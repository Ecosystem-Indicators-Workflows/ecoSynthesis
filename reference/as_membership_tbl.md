# Coerce a data frame to membership_tbl

Coerce a data frame to membership_tbl

## Usage

``` r
as_membership_tbl(
  x,
  source_id,
  target_id,
  membership,
  interpreter,
  round = NULL
)
```

## Arguments

- x:

  A data frame

- source_id:

  Source concept column

- target_id:

  Target concept column

- membership:

  Membership column

- interpreter:

  Interpreter column

- round:

  Round column

## Value

A validated membership_tbl

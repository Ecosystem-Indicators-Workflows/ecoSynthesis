# A subset of expert cross-reference table in paired-columns format for development and testing

A subset of expert cross-reference table in paired-columns format for
development and testing

## Usage

``` r
TASVEG_mini_expert_paired
```

## Format

A tibble with 13 columns:

- VEG_GROUP:

  Vegetation group of the `source` unit in the TASVEG 5.0 dataset

- VEGCODE:

  Original vegetation code of the `source` unit in the TASVEG 5.0
  dataset

- VEGCODE_D:

  Description of the `source` unit

- Notes:

  Notes on the `source` unit

- workflow:

  Workflow information for the `source` unit

- GET1:

  First expert assessment of the `source` unit

- GET1_p:

  Membership value for the first expert assessment of the `source` unit

- GET2:

  Second expert assessment of the `source` unit

- GET2_p:

  Membership value for the second expert assessment of the `source` unit

- GET3:

  Third expert assessment of the `source` unit

- GET3_p:

  Membership value for the third expert assessment of the `source` unit

- GET4:

  Fourth expert assessment of the `source` unit

- GET4_p:

  Membership value for the fourth expert assessment of the `source` unit

# Performs checks on a membership table

Performs checks on a membership table

## Usage

``` r
check_membership(x, source = NULL, target = NULL)
```

## Arguments

- x:

  A membership_tbl

- source:

  Lookup table for the source classification

- target:

  Lookup table for the target classification

## Value

List with checks results

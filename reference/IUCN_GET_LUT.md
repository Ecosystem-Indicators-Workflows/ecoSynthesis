# A Look-up Table for the IUCN Global Ecosystem Typology

The IUCN Global Ecosystem Typology (GET) is the first internationally
agreed framework for describing and mapping the world's ecosystems. This
is a Look-up Table generated from the Global Ecosystem Typology
vocabulary at https://w3id.org/iucn-get/IUCNEcosystemTypology.

## Usage

``` r
IUCN_GET_LUT
```

## Format

A data frame with 9 columns:

- efg:

  Character vector with urls of the permanent ID of the concept in the
  vocabulary

- efg_id:

  Character vector of short code for the ecosystem functional groups
  (level 3 in the classification)

- efg_name:

  Character vector of the name for the ecosystem functional groups
  (level 3 in the classification)

- biome_id:

  Character vector of short code for the functional biomes (level 2 in
  the classification)

- biome_name:

  Character vector of the name for the functional biomes (level 2 in the
  classification)

- realm_id:

  Character vector of short code for the realms (level 1 in the
  classification)

- realm_name:

  Character vector of the name for the realms (level 1 in the
  classification)

- version:

  Character vector with version name

- version_date:

  Character vector with date version was uploaded or updated

## Source

Keith, D. A., J. R. Ferrer-Paris et al. (2022) A function-based typology
for Earth’s ecosystems Nature 610, 513–518.
DOI:10.1038/s41586-022-05318-4.

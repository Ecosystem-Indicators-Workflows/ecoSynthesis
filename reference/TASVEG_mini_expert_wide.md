# A subset of interpreter cross-reference table in wide format for development and testing

A subset of interpreter cross-reference table in wide format for
development and testing

## Usage

``` r
TASVEG_mini_expert_wide
```

## Format

A tibble with 13 columns:

- VEG_GROUP:

  Vegetation group of the `source` unit in the TASVEG 5.0 dataset

- VEGCODE:

  Original vegetation code of the `source` unit in the TASVEG 5.0
  dataset

- VEGCODE_D:

  Description of the `source` unit

- Notes:

  Notes on the `source` unit

- workflow:

  Workflow information for the `source` unit

- GET1:

  Interpreter's first target classification of the `source` unit

- GET1_p:

  Membership value for the first interpreter classification of the
  `source` unit

- GET2:

  Interpreter's second target classification of the `source` unit

- GET2_p:

  Membership value for the second interpreter classification of the
  `source` unit

- GET3:

  Interpreter's third target classification of the `source` unit

- GET3_p:

  Membership value for the third interpreter classification of the
  `source` unit

- GET4:

  Interpreter's fourth target classification of the `source` unit

- GET4_p:

  Membership value for the fourth interpreter classification of the
  `source` unit

# A subset of the TASVEG dataset for development and testing

A subset of the TASVEG dataset for development and testing

## Usage

``` r
TASVEG_mini
```

## Format

A tibble with 4 columns:

- VEGCODE:

  Original vegetation code of the `source` unit in the TASVEG 5.0
  dataset

- efg:

  Code for the `target` Ecosystem Functional Group

- memb:

  Membership value between 0 and 1, indicating the degree of membership
  of the vegetation unit to the `target` EFG

- expert:

  Expert who provided the membership value
